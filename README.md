# SmartHire – Resume and Job Match Analyzer

SmartHire is a Java-based web application built with Spring Boot. It is designed to help users analyze resumes and explore how their skills relate to job requirements.

## Project Overview

This project is developed as a learning and portfolio project to practice Java, Spring Boot, web development, and database integration.

## Technologies Used

- Java 21
- Spring Boot
- Maven
- MySQL
- HTML and CSS
- Thymeleaf
- Apache PDFBox

## Current Status

- Spring Boot application starts successfully.
- Homepage is available locally.
- MySQL database configuration is included.

## Getting Started

### Prerequisites

- Java JDK 21
- Apache Maven
- MySQL Server

### Run Locally

1. Clone this repository.
2. Create a MySQL database named `smarthire_db`.
3. Configure the database username and password using environment variables.
4. Open a terminal in the project directory.
5. Build the project:

   `mvn clean package`

6. Run the application:

   `java -jar target/smarthire-1.0.0.jar`

7. Open `http://localhost:8080` in your browser.
